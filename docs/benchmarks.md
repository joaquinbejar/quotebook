# quotebook compute-unit costs

Generated by `make bench` (`program/tests/cu.rs`) in LiteSVM. Each figure is the `compute_units_consumed` of a one-instruction transaction, including the system program CPIs. Keys and mint addresses are fixed, so the PDA bump searches (about 1,500 CU per attempt) are the same on every run; with other keys a creation can cost a few thousand CU more.

| Instruction | Case | CU |
| --- | --- | ---: |
| `init_config` | upgrade-authority gate + config PDA search + create | 4650 |
| `create_series` | two SPL Token mints | 7865 |
| `create_series` | Token-2022 base with MetadataPointer + TokenMetadata | 8406 |
| `init_maker` | maker and delegate PDA searches + create (2,120 bytes) | 4554 |
| `cancel_nonce` | inside the window, no slide | 1677 |
| `cancel_nonce` | slides 64 nonces (one word) | 1720 |
| `cancel_all` | slides 100 nonces | 1749 |
| `cancel_all` | slides 16,383 nonces, unaligned, wrapping (worst case) | 1789 |
| `cancel_all` | slides a whole window or more (clears the ring) | 1697 |
