# quotebook compute-unit costs

Generated by `make bench` (`program/tests/cu.rs`) in LiteSVM. Each figure is the `compute_units_consumed` of a transaction holding only that instruction (for `settle`, also the ed25519 precompile instruction before it), including the system and token program CPIs. Keys and mint addresses of the creation rows are fixed, so the PDA bump searches (about 1,500 CU per attempt) are the same on every run; with other keys a creation can cost a few thousand CU more. `settle` does no bump search, so its cost does not depend on the keys. The precompile itself consumes no compute units (measured below); it costs one signature in the transaction fee.
